# Design schema

Use this structure when producing the JSON design schema. Fill it with details from the supplied design and project context.

```json
{
  "designSystem": {
    "colors": {},
    "typography": {},
    "spacing": {},
    "breakpoints": {},
    "shadows": {},
    "borderRadius": {},
    "animations": {}
  },
  "components": {
    "[ComponentName]": {
      "variants": [],
      "states": [],
      "props": {},
      "accessibility": {},
      "responsive": {},
      "interactions": {}
    }
  },
  "layouts": {},
  "patterns": {}
}
```
